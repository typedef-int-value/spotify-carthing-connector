# Car Thing 공통 프로토콜 라이브러리

- `CarThing.Core` 프로젝트 분리, 대상 프레임워크 `net10.0`
- Windows API·WinForms·NAudio 의존성 제거, MessagePack `3.1.12` 사용
- Windows 트레이 앱의 프로젝트 참조로 공통 코드 연결
- 외부 미디어·Spotify 화면 모드 및 기존 메시지 형식 유지

| 경로 | 역할 |
|---|---|
| `carthing-core/MediaBridge.cs` | WAMP 인증·구독·RPC·상태 발행·프레임 송수신·캡처 |
| `carthing-core/IMediaSource.cs` | 플랫폼별 미디어 조회·커버 조회·제어 계약 |
| `carthing-core/MediaCommands.cs` | 재생·셔플·볼륨 명령 판별 및 인자 검증 |
| `carthing-core/MediaImageCache.cs` | 최근 이미지 8개 보관 |
| `carthing-core/MediaBridge.SelfTest.cs` | 기존 프로토콜 회귀 시험, EXE 진단 인자에서 재사용 |
| `windows-probe/Program.cs` | Windows Bluetooth 장치 조회·RFCOMM 연결·소켓 수명 관리 |
| `windows-probe/WindowsMedia.cs` | `IMediaSource` 구현, Windows 미디어 세션·JPEG 변환 |
| `windows-probe/WindowsVolume.cs` | Windows 오디오 출력 장치의 볼륨 조회·제어 |
| `windows-probe/ConnectorTray.cs` | 트레이·설정·모드 전환 |
| `tests/CarThing.Core.Tests/` | 플랫폼 독립 실행 시험, 가짜 미디어 공급자·메모리 스트림 |

## 플랫폼 연결 계약

| 항목 | 계약 |
|---|---|
| `IMediaSource.ReadAsync()` | 현재 미디어의 `player_state` JSON 반환 |
| `ReadVolumeAsync()` | `volume`·`volume_steps` JSON 반환, 상태 부재 시 `null` |
| `GetImage(id)` | `image_data` Base64·크기 JSON 반환, 캐시 부재 시 `null` |
| `ControlAsync(uri, arguments)` | 제어 수락 시 `true`, 거절 시 `false`, 잘못된 인자는 `ArgumentException` |
| `MediaBridge.RunAsync(...)` | 연결된 입력·출력 `Stream`, 미디어 공급자, 캡처 경로, 화면 모드, 소켓 종료 콜백, 취소 토큰 전달 |
| 소켓·스트림 | 플랫폼 호출부 소유, 종료 콜백에서 대기 중인 읽기를 해제하도록 소켓 닫기 |
| 호출 순서 | 연결별 프로토콜 객체 1개, 송신·상태 변경 순차 처리 |
| 캡처 경로 | 플랫폼에서 쓰기 가능한 기존 디렉터리의 파일명 접두사 지정 |

- JSON 필드: [플랫폼 공통 프로토콜 사양](52_CarThing_연동_프로토콜_사양.md) 참조
- Android 연결 지점: `CarThing.Core` 참조, `IMediaSource` 구현 및 RFCOMM 스트림 전달
- Android 커버 처리: 플랫폼 이미지 API의 JPEG 변환 후 `MediaImageCache` 저장
- Windows 단일 EXE 배포 설정 유지, 공통 라이브러리 포함 방식
