# carthing-connector

Windows 공통 미디어 세션의 곡 정보·앨범 이미지를 순정 Car Thing에 전달하고 재생·볼륨을 제어하는 트레이 앱.

- 실행: `dist/carthing-connector/carthing-connector.exe` 더블클릭
- 첫 실행에서 페어링된 Car Thing 선택, 이후 저장된 장치로 연결 대기
- 트레이 우클릭: 장치 선택·연결 다시 시작·로그 폴더 열기·종료

- 순정 화면 시험: `carthing-connector.exe --spotify-ui-experiment` (기존 앱 종료 후 실행)
